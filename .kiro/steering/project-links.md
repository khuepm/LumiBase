# Project Links & Identity

## Official URLs

- **GitHub Repository**: https://github.com/khuepm/lumibase
- **Website**: https://lumibase.dev

## Rules

- NEVER use `https://github.com/lumibase/lumibase` — this is NOT the official repo.
- The correct GitHub org/user is `khuepm`, not `lumibase`.
- When generating links to the project source, always use `https://github.com/khuepm/lumibase`.
- When referencing the project website, use `https://lumibase.dev`.
