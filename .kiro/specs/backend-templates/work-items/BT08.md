## Outcome and scope
Provide catalog/import JSON/export/capture surfaces, revision selector, explicit site selector, schema/relations preview, seed toggle default off, conflict/error views and result links. Use shared plan/apply service, show approval state for governed operations. Keep selected site fixed through planning and confirmation; changing site invalidates plan.


## Implementation work breakdown
- [ ] BT08-W1: Build catalog/JSON import/capture/export and exact revision selection views using shared APIs.
- [ ] BT08-W2: Implement explicit site picker, schema/relationship inventory and opt-in seed pack selection with counts.
- [ ] BT08-W3: Implement plan confirmation, governed approval state and installation results; invalidate preview on any plan-affecting change.

## Expected code touchpoints
apps/studio template module + navigation/API client; shared contracts; shell compatibility checks. These are planning boundaries, not exclusive file grants; coordinate shared changes and preserve unrelated work.
