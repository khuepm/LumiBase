## Outcome and scope
Ship wordpress-alike 1.0.0: authors (content profiles, not auth accounts), posts, pages, categories, tags, post_categories, post_tags and comments; explicit relation fields/junctions, defaults/validation and supported display metadata. One canonical schema, no seed by default, optional demo seed pack. Publish precise component inventory and no WordPress/PHP/plugin/API compatibility claim.


## Implementation work breakdown
- [ ] BT07-W1: Replace illustrative fixture with production-validated wordpress-alike revision and actual supported CMS compatibility range.
- [ ] BT07-W2: Complete inventory/constraints and author/post/page/comment/taxonomy references; explicitly document content author vs auth user.
- [ ] BT07-W3: Provide canonical schema plus bounded synthetic demo pack; lightweight is seedMode=none, not a divergent schema.

## Expected code touchpoints
bundled official template artifact location agreed with BT02; fixture/acceptance tests; EN/VI template inventory. These are planning boundaries, not exclusive file grants; coordinate shared changes and preserve unrelated work.

- [ ] Compare installed schema to artifact: exactly authors, posts, pages, categories, tags, post_categories, post_tags, comments plus declared fields/relations; no missing or extra template-owned resources.

- Verification/evidence: Item validation tests; attach test name, exact command, commit SHA and actual result.

### BT07-AC04 — Lightweight

- [ ] Install without seed; all 8 collections contain zero rows; model fingerprint matches the demo variant's schema fingerprint.
- Verification/evidence: DB comparison; attach test name, exact command, commit SHA and actual result.

### BT07-AC05 — Demo coherence

- [ ] Demo pack exercises all 8 collections and every declared relation kind, including parent-child examples; all records are synthetic, no auth users/files/secrets.
- Verification/evidence: Fixture integrity + DB; attach test name, exact command, commit SHA and actual result.
