### Row 6 — the AC-1 probe

Round 1 inferred AC-1 from adjacent suites. To measure it directly I added a throwaway
`src/services/__tests__/zz-c03-probe.db.integration.test.ts`, ran it against the disposable DB, and **deleted it** (tree verified clean afterwards; nothing proposed for the repo). It built a real `AISecureHarness` with `enableAgentHarnessAudit: true` and a `SchemaService` spy, then asserted:

1. `execute('deleteCollection', { name: 'posts' }, ['*'])` returns `pending_approval` and the spy has **zero** calls — the dangerous call parks with no schema side effect.
2. The returned `agentApprovalId` is a row with `status='pending'` whose `legacyApprovalId` equals the returned `approvalId` and whose `runId` matches — i.e. the id handed back is exactly the one `POST /agent/approvals/:id/decide` takes, and it resolves to the stored action.
3. The run is `awaiting_approval` and the tool call is `pending_approval` with `approvalId` set — parked, visible, not lost.
4. `executeApproved(...)` then calls the spy **once** with `'posts'`; both approval records become `approved` with `decidedBy` set and the run ends `succeeded`.
5. A harness scoped to another `siteId` is **denied** with zero spy calls; a caller with only `items:read` is **denied** with zero spy calls.
