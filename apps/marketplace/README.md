# Lumibase Marketplace

The official marketplace for [lumibase.dev](https://lumibase.dev).

🌐 **Live:** [marketplace.lumibase.dev](https://marketplace.lumibase.dev)

## Overview

Lumibase Marketplace is the central hub where the Lumibase community can
discover, share, and install extensions, templates, and integrations for
the Lumibase platform.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/lumibase-ai/marketplace.git
cd marketplace
```

## Contributing

Contributions are welcome! Whether you want to publish something to the
marketplace or improve the platform itself, please open an issue or submit
a pull request.
