# Project Rules for Claude

## Git & Commits

- **Commit author:** always use `Javier <javier@genuis.app>`.
- **Do NOT add a `Co-Authored-By` trailer** to commit messages.
- **Do NOT add any co-author, `Claude-Session`, or attribution trailers** to commits.
- Keep commit messages clean and descriptive — the message body only.

## Pull Requests

- **Do NOT include** "Generated with Claude Code" or any similar
  attribution / generated-by line in PR titles or descriptions.
- Write PR descriptions with only the relevant summary and changes.
